# Sift v1.1.0

Duplicates got a rebuild: you can see each set of copies side by side, choose which one stays, and remove copies one set at a time instead of all at once.

## Duplicates

- **Remove one set at a time.** Before, the only choice was to remove every extra copy Sift found in one go. Now each set has its own **Remove extras** button, so you can clear the copies you're sure about and leave the rest for later. The set leaves the list as soon as it's done, and the total at the bottom drops to match. **Remove all extra copies** is still there when you want to do everything at once.

- **See the copies before you choose.** Pick a set and its copies appear side by side: a preview, where each one lives, and when it was last changed. Sift also shows what makes them the same — identical contents, byte for byte, plus details like size, resolution or length — and points out when only the name or folder differs. On a Mac, previews are the same thumbnails Finder shows; on Windows and Linux, photos show as themselves and everything else gets a simple tile.

- **You decide which copy stays.** Choose a rule at the top — keep the **Oldest**, the **Newest**, or the one in the **Best place** (anywhere other than Downloads or the Desktop) — or click any copy to keep that one instead. **Keep all copies** leaves a set alone completely.

- **Easier to find things.** Search by name or folder, filter by Photos, Videos, Audio, Documents or Other, and sort by how much space a set would free. Long lists are split into pages.

- **Fewer false duplicates.** Some files are one file with two names (a "hard link"). They looked like duplicates before, but removing one name frees nothing, so Sift no longer lists them. You may see a few fewer sets, and the amount on the Duplicates page may drop a little.

Nothing changes about safety: extra copies you remove, whether one set or all of them, go to Restore and wait there for 30 days in case you need them back.

## Works on

- **macOS** 10.15+ (Apple Silicon and Intel)
- **Windows** 10+ (x64 and ARM64)
- **Linux** (x86_64)
